# Глоссарий KROTTUN

- **Основной сервер** — выбранный пользователем сервер, который всегда пробуется первым.
- **Резерв** — включённый сервер из упорядоченного списка, используемый после основного при отказе.
- **Очередь сессии** — зафиксированные для одного подключения основной сервер и резервы в порядке попыток.
- **Защита** — сетевой режим блокировки, который сохраняется при отказах подключения и исчерпании очереди.
- **Диагностика** — разовая проверка активного защищённого подключения либо одного выбранного сервера до подключения; сама не меняет сетевой режим.
