# Прототипы терминального журнала KROTTUN

Статус: визуальные концепты для выбора пользователя. Код программы не изменён. Все строки соединений на изображениях — демонстрационные.

1. **Graphite** — нейтральная таблица, боковая панель выбранного соединения. `01-graphite.png`.
2. **Phosphor** — зелёный терминальный поток, фильтр-команда внизу. `02-phosphor.png`.
3. **Amber Console** — янтарная консоль с нижней панелью деталей. `03-amber-console.png`.

Создано встроенным image_gen, три независимые генерации; исходники сохранены в CODEX_HOME/generated_images. Это дизайн-превью, не интерактивные макеты и не заявления о текущих событиях сети.
