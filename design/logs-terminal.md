# Журнал KROTTUN: ASCII Terminal

Одобренный референс: `log-prototypes-2026-10-23/04-ascii-reference.png`, пользователь: «да пойдет».

## Применение
Только `body.terminal-logs`, включается вкладкой «Соединения». При выходе исходная тема приложения восстанавливается. Нативные оконные кнопки не дублируются в HTML. Предупреждения, статус и снятие защиты доступны.

## Визуальный язык
- Фон #000, основной текст #e6ece7, лайм #80f25a, циан #00e6ee; домен — основной циановый акцент.
- Локальные Consolas/Courier New; никаких запросов шрифтов или изображений извне.
- Пунктирные/ASCII-рамки, квадратные скобки у управления, прямоугольные поверхности, без фонового свечения/карты в журнале.
- KROTTUN нарисован редактируемыми 5×7 pixel glyphs; первые четыре буквы лайм, остальные циан. Изображение-прототип не используется фоном.
- Компактная шапка, фильтр/пауза/очистка, прокручиваемая таблица, выделение и нижний инспектор. Значения без произвольных переносов; на узком экране таблица прокручивается горизонтально.

## Поведение
Выбор привязан к connection_key и сохраняется при обогащении строки доменом. Фильтр, пауза, очистка и выбор клавиатурой поддерживаются. Счётчики и страны берутся из данных, неизвестные значения не выдумываются. Исторический статус — «Зафиксировано».

Окно расширяется в сторону 1120×820, ограничено рабочей областью монитора, возвращает предыдущие размеры/позицию при выходе. Координаты WinForms WorkingArea нормализуются по точному window.native._scale; 150% DPI/отрицательный origin покрыты тестом.

87 tests OK, JS syntax/unique IDs OK, source review SAFE. Detector запущен один раз, четыре замечания к прежним стилям других вкладок оставлены в рамках scope.
