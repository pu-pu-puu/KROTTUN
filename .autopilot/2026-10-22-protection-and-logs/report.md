# Результат: код готов к сетевой приёмке

Реализованы persistent WFP-защита, последовательное резервирование и вкладка «Соединения». Остановка/закрытие сохраняет защиту. Отдельная команда освобождает интернет после подтверждённого завершения ядра.

База: KROTTUN v2.4.0, 12fd896. Процесс: Autopilot v2.2.0 (25b5fba). Ветка `feature/protection-and-connection-log`. Код: 8ea3207, исправления aae6b03 и 4ef6a51.

## Проверено
- 28 unit-тестов проходят (было 15), в том числе offline sing-box check для HTTP/SOCKS.
- Независимая приёмка из чистого клона с существующими зависимостями: 28 tests OK; fake failover, сохранение deny до старта/после stop, release и Bearer journal PASS.
- JavaScript syntax и HTML IDs проверены исполнителем. Python compile прошёл.
- Ревью выявило ошибки неподтверждённого stop, ранней отмены и зависания STOPPING; исправлены с regression tests.

## Окончательная приёмка не пройдена
Реальные системные фильтры, туннель и приложение на рабочем компьютере не запускались. Отсутствие утечек не подтверждено. Обязательна изолированная Windows VM с packet capture: старые соединения, DNS/IPv6, обрыв прокси/сети, завершение ядра/GUI, reboot, BOOTTIME/BFE, смена интерфейса. До этого выпуск запрещён.

Интерактивный UI, live `/connections`, чистая установка зависимостей не проверены. Журнал — snapshots активных соединений: короткие могут пропускаться, содержимое HTTPS не раскрывается. Проверки ограничены, гарантий обхода антифрода нет. UDP отклоняется; DNS endpoint разрешается до включения защиты и кэшируется.

## Что нужно от пользователя
Секреты и переменные окружения не требуются. Следующий технический этап — Windows VM для сетевой приёмки. Готовый exe не собирался и релиз не публиковался.

## Что не вошло
MITM/расшифровка HTTPS, гарантия отсутствия антифрод-блокировок — вне рамок. Полный захват каждого короткого соединения не реализован; ограничение явно отражено в журнале и документации.

## Восстановление
Использовать явную кнопку снятия защиты. Аварийный вариант из повышенного PowerShell в каталоге проекта: `python -m core.kill_switch --release`. Эта команда меняет реальные сетевые фильтры; в ходе разработки выполнялся только `--help`.
