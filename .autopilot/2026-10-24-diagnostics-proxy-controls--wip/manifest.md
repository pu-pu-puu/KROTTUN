# Манифест требований

Источник: 2026-10-24-brief.md. Требование снимает только пользователь.

| ID | Из брифа (дословно) | Статус | Основание | Где |
|---|---|---|---|---|
| R01 | «Диагностика одной кнопкой» | in-ticket | Проверки прокси, DNS, HTTPS, IP, системного прокси; ограниченные по времени, без изменения сети | spec: Диагностика → T03 |
| R02 | «Редактирование прокси» | in-ticket | Адрес, порт, протокол, логин, пароль, название; сохраняется id; изменения не подменяют активную сессию | spec: Редактирование → T01 |
| R03 | «Управление резервами» | in-ticket | Явный список, порядок и исключение; снимок фиксируется при подключении | spec: Резервы → T02 |
| R04 | «через скил автопилот» | in-ticket | Артефакты, исполнители, независимое ревью, изолированная приёмка | spec: Доставка → T01, T02, T03 |
