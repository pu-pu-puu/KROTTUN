# ADR 0002: Числовые endpoint закреплены за активной сессией

## Контекст
Редактирование hostname должно инвалидировать кеш для будущих подключений. При этом активная сессия может использовать доменный резерв, разрешённый до перехода в RUNNING.

## Решение
После начального разрешения имён сохранить числовые endpoint в снимке сессии до публикации RUNNING. Редактирование очищает только кеш будущих подключений; текущая сессия продолжает использовать свой исходный числовой endpoint без нового DNS-запроса.

## Почему
Сброс общего кеша вместе с повторным разрешением имени изменил бы адрес резервного сервера посреди активной защищённой сессии. Сохранение одного hostname-кеша также оставило бы устаревший адрес для будущих подключений.

## Последствия
Текущий резерв остаётся привязан к проверенному при старте адресу, а следующее подключение использует свежие данные DNS. Изменения адреса не перестраивают активный runtime.
