# ADR 0001: Снимок кандидатов на сессию подключения

## Контекст
Редактирование серверов и очереди резервов разрешено во время работающего туннеля. Watchdog должен продолжать попытки в той же последовательности, не подхватывая новые или исключённые записи.

## Решение
При ручном подключении фиксировать копии основного сервера и резервов в неизменяемом снимке сессии. Начальный запуск и watchdog используют этот снимок и его оставшийся суффикс; сохранённые записи остаются отдельными от активных.

## Почему
Чтение изменяемого списка при каждой попытке смешивает настройки следующего подключения с текущей сессией и может вернуть уже исчерпанного кандидата. Снимок сохраняет выбранный порядок и границы сессии.

## Последствия
Правки во время RUNNING сохраняются для следующего ручного подключения, текущая сессия их не видит. Watchdog не расширяет очередь; после исчерпания кандидатов защита остаётся включённой до ручного повтора.
